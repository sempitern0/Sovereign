# Security policy

Report vulnerabilities privately using GitHub Security Advisories if enabled; otherwise contact the maintainer privately. Do not post credentials or exploitable details in public issues.

H0 is a development scaffold: it cannot install packages or authenticate to remote services. App sources remain pending validation. Before enabling installers, require verified origins and publisher identities, explicit plan/consent, least privilege, safe command invocation and redacted logs. SHA-256 from an untrusted source alone does not establish authenticity.

See [initial threat model](docs/security/threat-model.md).
